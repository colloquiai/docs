<Update label="November 2026" description="Contacts Directory">
  Agents can now transfer calls and send SMS to people and teams kept in a workspace **Contacts Directory**, instead of numbers typed into each tool.

  - **Contacts Directory.** Directories hold contacts and departments, with availability windows, a preferred transfer type and number per contact, and CSV import and export. Link directories to an agent under **Contacts**. See [Contacts Directory](/core-concepts/contacts).
  - **Transfer Call.** The phone directory is optional once directories are linked. A contact outside its availability window is not dialled; a Transfer Call node gets a fixed **Transfer unavailable** transition for that case, and **Max Transfer Attempts** caps failed transfers per call.
  - **Send SMS.** A new **Contacts / Departments** recipient option texts chosen contacts and every member of chosen departments.
  - **Variables.** `transfer_target_*`, `transfer_attempts` and `contacts.<id>.<field>` are available wherever variables are used. See [Variables](/conversation-flows/variables).
  - **API.** Fifteen endpoints for directories, contacts and departments, plus `contacts_config` on Create and Update Agent.
</Update>

<Update label="November 2026" description="Documentation">
  Documentation relaunched with guides for every part of the platform, a conversation-flow section, and a refreshed API reference.

  - **Guardrails API.** Create, list, update and delete guardrails by API, and attach them to agents with `guardrails_config`.
  - **API reference** regenerated from the current platform, including the full conversation-flow node schema on Create and Update Agent.
</Update>
